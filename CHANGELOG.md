# STAGEFLIP — Changelog

**Made by Cappuccino Digital**

## 1.0.0 — November 3, 2026

First public release.

- One-click Show + Key and Hide + Key for managed Collections.
- Independent viewport and render visibility channels, with batch keyframing.
- Native Scene Action F-Curves, constant key insertion and native editor support.
- Explicit confirmation before removing animated bindings; inactive Action,
  shared Action and read-only data safeguards.
- Save/reopen, native Undo/Redo and visibility evaluation during playback/rendering.
- Installation instructions, user guide and complete GPL-3.0-or-later source.

Tested on Windows x64 using Blender 5.2.3 LTS. Other platforms and Blender versions
are untested. See the user guide for limitations.
