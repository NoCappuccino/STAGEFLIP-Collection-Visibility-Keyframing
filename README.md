# STAGEFLIP — Collection Visibility Keyframing

**Made by Cappuccino Digital**  
Free, open-source Blender extension · **v1.0.0**

Animate entire Blender Collections with one-click **Show + Key** and **Hide + Key** controls, without keyframing individual objects.

## Features

- Independently animate **Viewport**, **Render**, or **Both** visibility channels
- Manage and keyframe multiple Collections at once
- Use native Blender animation keyframes with Timeline and Dope Sheet editing
- Stepped visibility changes, scrubbing and playback
- Save animation inside your `.blend` files
- No sign-in, activation, or network connection required

## Download and install

1. Open the [Releases page](https://github.com/NoCappuccino/STAGEFLIP-Collection-Visibility-Keyframing/releases).
2. Download **`stageflip_v1.0.0.zip`** from the v1.0.0 release assets (once published). **Do not use GitHub's automatic “Source code (zip)” download as your Blender extension installer.**
3. In Blender, choose **Edit → Preferences → Get Extensions → Install from Disk**, then select the STAGEFLIP ZIP.
4. In the 3D Viewport, press **N** and open the **STAGEFLIP** tab.
5. Choose a Collection, click **Add**, move to a frame, then use **Show + Key** or **Hide + Key**.

## Compatibility

Tested with **Blender 5.2.3 LTS on Windows x64**. macOS, Linux, other Blender versions, and concurrent multi-Scene rendering have not been verified. Render workers must also have STAGEFLIP installed and enabled.
